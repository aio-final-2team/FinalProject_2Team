# 서체

| 용도 | 서체 | 클래스 |
| --- | --- | --- |
| 제목·짧은 라벨(큰 제목, 묶음 제목, 아이 이름, 주 버튼, 칩·태그·상태 알약, 항목 이름, 아래 탭 이름) | **학교안심 둥근미소**(보통·굵게) | `font-display`, `h1`·`h2`·`h3`는 기본 |
| 본문(문장·설명·경고 글)·숫자·시간·입력칸 글자 | Pretendard | 기본(`font-sans`) |

학부모·교사·원장 화면 모두 같다(2026-11-26 성주 확정). 나눔스퀘어라운드·몽글몽글·배민 주아는 쓰지 않는다.
서체 이름은 `src/styles/index.css`의 `--font-display` 한 줄로 바꾼다.

## 라이선스
학교안심 둥근미소는 KERIS(한국교육학술정보원)가 배포하는 SIL OFL 1.1 서체다. 교육저작권지원센터 안내에서 웹사이트·UI/UX·임베딩·상업적 이용이 허용된다. 폰트 파일 자체를 파는 것만 금지다.
라이선스 원문은 `public/fonts/LICENSE-HakgyoansimDunggeunmiso.txt`에 있고, 서체 파일과 같이 배포한다.

## 파일 크기를 줄인 방법
공식 원본(TTF)에서 한글 완성형 11,172자와 영문·숫자·기호만 남겼다(보통 약 109KB, 굵게 약 136KB). 아이 이름의 드문 글자도 둥근미소로 나온다. 앞으로 만들 안드로이드 앱도 같은 파일을 쓴다.

## 출처
2026-11-26에 교육저작권지원센터 [학교 안심폰트](https://copyright.keris.or.kr/wft/fntDwnld)에서 받은 공식 원본(둥근미소 R·B, 2024-08-21 배포본)으로 만들었다. 다시 만들 때는 `pip install fonttools brotli` 뒤 `python3 scripts/build-fonts.py <R 파일> <B 파일>`을 실행하고, 화면에서 글자를 확인한 뒤 `public/fonts/`의 두 파일을 교체해 커밋한다.

## 알아 둘 것
- 글자를 잘라 만든 파일은 OFL에서 "수정본"이다. 이 서체에는 예약된 이름(Reserved Font Name)이 없어서 이름을 바꾸지 않아도 되지만, 라이선스 문서의 저작권자 줄은 공식 배포처 안내와 맞는지 가끔 확인한다.
- 둥근미소는 굵기가 보통·굵게 둘뿐이다. 중간 굵기(500·600)는 가까운 쪽으로 나온다.
