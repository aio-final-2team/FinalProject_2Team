# apps/api/app/modules/requests

학부모 요청의 생성·목록·상세·대화·확인·스트림을 처리해요.
requests.py에서 범위 검사와 저장을 같은 트랜잭션으로 묶어요.
runner.py는 설정 입구 호출·실패 인계·카드 누락 점검을 맡아요.
agent_stub.py는 모의 분류·카드·상담 후보를 저장해요. 실제 모델은 부르지 않아요.
complaints.py의 반복 집계를 원장 보고 생성과 카드 조회가 함께 써요.
같은 기관·반·주제의 민원 분류는 트랜잭션 자문 잠금으로 순서대로 반영해요.
events.py는 요청 이력과 앱 안 알림을 상태 변경과 함께 저장해요.
카드 결정은 modules/cards에 있어요. 상담 시간 선택·주기 실행은 후속 항목에서 연결해요.
