유치온 QA 도구

QA 서버에서만 열리는 페이지예요. 화면 QA는 웹 화면에서 내 QA 계정으로 하고, 여기서는 처음으로 되돌리기와 오류 찾기만 해요.

서버 판을 읽는 중이에요…

1. 로그인

웹 화면과 같은 QA 계정으로 들어가요. 예: sj.teacher01

2. 내 원 처음으로

내 QA 원의 요청·카드·알림장·기억·소식을 모두 지우고 시드 상태로 다시 채워요. 다른 사람 원과 시연 원은 그대로예요.

3. 알림장만 다시 시험하기

한 반·한 날짜의 알림장 입력·아이별 알림장·확인 카드·알림만 지워요. 학부모 답장 문의는 남아요. 그 반 담임과 원장만 돼요.

4. 요청 ID로 오류 찾기

화면에서 이상하면 개발자 도구 → 네트워크 → 그 요청의 응답 헤더 X-Request-ID를 붙여 넣어요. 오류 응답이면 본문 error.trace_id도 같은 값이에요.
