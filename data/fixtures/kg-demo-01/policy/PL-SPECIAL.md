# 특별활동·방과후 프로그램 요일과 영어 수업

- 대상 반: 전체
- 시행일: 2026-09-01

## 특별활동은 어떤 걸 하나요·영어도 하나요
- 특별활동은 선택 프로그램이며 방과후 시간 15:20~16:00에 진행합니다.
| 요일 | 특별활동 |
| --- | --- |
| 월 | 체육 |
| 화 | 영어 |
| 수 | 음악(오르프) |
| 목 | 미술 |
| 금 | 과학놀이 |
- 선택 특별활동비는 월 40,000원(가상)입니다.
- 방과후 과정비는 월 70,000원(가상)이며 신청한 달에만 청구합니다. 방과후 과정은 14:00~18:00입니다.
