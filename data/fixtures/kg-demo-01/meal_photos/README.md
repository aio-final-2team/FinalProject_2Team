# 급식 참고 사진 38장

식단 칸(교사 홈·식단표 화면·학부모 홈)에 보여 주는 그날 점심 사진이에요. **실제 급식 사진이 아니라, 우리 원 식단표 점심 메뉴를 바탕으로 AI가 만든 참고 사진**이에요. 화면에도 "참고 사진"이라고 밝혀요.

- 대상: [`../menu`](../menu)의 주간 식단표 8주(11/16~1/15) 점심 38끼. 11/26은 현장체험학습이 없는 반의 비빔밥이에요
- [`meal_photos.json`](meal_photos.json): 날짜·식단표 점심 원문(`lunch`)·주메뉴(`main_dish`)·파일·만든 도구·프롬프트
- 쓰는 곳: 기동 시드(`db/seeds/photos.py`)가 원마다 `MEDIA_DIR/meals/<원 ID>/<날짜>.webp`로 복사하고 `meal_photos` 표에 적어요. 화면은 API 76(목록)·77(파일)로 받아요
- 식단표를 고치면 그 날짜 사진도 다시 만들어야 메뉴와 맞아요. 사진 이름과 메뉴가 다르면 `meal_photos.json`의 `lunch`부터 확인해 주세요

예전에 프론트가 쓰던 [`../../public_meals`](../../public_meals)는 다른 기관의 공개 식단 사진이라 우리 원 메뉴와 맞지 않았어요. 그 자료는 공개 식단 수집 기록으로만 남겨 둬요.
