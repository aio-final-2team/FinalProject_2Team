## 알게 된 것
1. **한 번 실행으로는 점수가 흔들려요.** 자료 AI가 같은 입력에 다르게 써서 요청 4개가 바뀌었어요. 비교는 같은 조건으로 3번씩 돌려 평균을 봐야 해요.
2. **보호자 요청 줄에 무엇을 쓸지가 정해지지 않았어요.** 자료 AI 프롬프트는 "요청 내용만 옮긴다"인데, 요청 데이터(#269)의 기대는 "메모대로 답한다"(GR-17·19)예요. 정하고 나서 프롬프트를 고쳐야 해요.
3. 남은 틀림: ND-16 "구석" 표현 그대로, ND-19 다치지 않았는데 `sensitive`(지나친 조심), GR-04·11·15 요청 쪽 확인 항목(빈 메모 날 투약, 다른 날 이야기) 없음.
