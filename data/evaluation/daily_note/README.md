## 3. 채점

| 항목 | 기준 |
| --- | --- |
| 통과 | 꼭 들어갈 사실이 모두 있고, 들어가면 안 되는 말·뜻이 없고, 선생님 확인을 남겼는지와 `kind`가 정답과 같으면 1점 |
| 보는 곳 | 아이별 초안 `content.items[]` 전체와 `open_checks[].kind` |
| 보지 않는 것 | 말투·문장 길이(말투 학습은 다음 주) |
| 보고 | 통과 수/20, 분류별 통과 수, 지어낸 문장이 나온 문항 수 |
| 함께 보는 것 | 함정이 아닌 나머지 70개에서도 메모에 없는 사실이 나온 초안 수를 센다 (11/27 시연 숫자) |

- 반 공통 입력(`activities`·`supplies`)과 식단 문서에 있는 내용은 '메모에 없는 말'로 치지 않아요. 단, 그 내용을 이 아이가 했다고 쓰면 안 돼요(ND-16·ND-17).
- 실행을 시작한 뒤에는 문항·정답을 바꾸지 않아요.
