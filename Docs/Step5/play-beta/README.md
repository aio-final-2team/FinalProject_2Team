## 완료 기준 확인 (WBS T70)

| 기준 | 상태 | 비고 |
| --- | --- | --- |
| 계정 접근·릴리스 권한 또는 담당자 확인 | 담당자 확인 | 계정 명의·관리: 지혜. 개발자 등록은 11/26~이번 주 안 예정 |
| Closed testing 트랙 준비 | 계정 열린 뒤 | 앱 만들기 → 비공개 테스트 트랙 생성 순서만 정리 |
| 테스터 목록 준비 | 구성 정함 | 팀원 4명·강사·외부 지인. 이메일은 저장소에 올리지 않음 |
| 피드백 채널 준비 | 팀 상의 중 | 후보 3안 정리, 팀 결정 뒤 반영 |
| 개인정보처리방침·Data safety·콘텐츠 등급·대상 연령 답변 초안 점검 | 초안 | 가상 데이터 기준, 앱 기능 기준으로 작성 |
| 미확정 사항 기록 | 기록 | 아래 표 |
