# 03 정책 답변 체크리스트 (초안)

> 2026-11-26 기준 · Play Console '앱 콘텐츠(App content)'에 넣을 답변 초안
> Data safety는 **베타에서 쓰는 가상 데이터가 아니라 앱 기능이 다루는 자료** 기준으로 적어요. 베타에 가상 데이터만 쓰는 건 따로 적어 둬요(NFR-12).

## 1. 대상 연령·Families

| 항목 | 초안 답변 | 근거 |
| --- | --- | --- |
| 대상 연령 | 18세 이상 | 쓰는 사람은 유치원 교사(만 3~5세 반 담당), 확장 시 학부모·원장으로 모두 성인 |
| 아동이 쓰는 앱인가 | 아니요 | 만 3~5세 아동은 앱을 쓰지 않고, 앱이 다루는 정보의 주인임 |
| Families 정책 | 적용 안 함 | 대상 연령에 13세 미만이 없음. NFR-12 '적용 여부 검토'의 결론 |
| 아동에게 관심을 끄는 앱인가 | 아니요 | 업무 앱(알림장·요청·상담) |

아동 정보를 다루는 건 Data safety와 개인정보처리방침에 적어요.

## 2. 개인정보처리방침

| 항목 | 내용 |
| --- | --- |
| 필요 여부 | 필요 (로그인·개인정보를 다룸) |
| 공개 위치 | 팀 서버 웹의 `/privacy`(로그인 없이 열림, 문구는 #384 처리방침 초안, 화면은 성주). 지금 주소가 `3-34-13-40.sslip.io`라 서버가 바뀌면 같이 바꿈 (README U3, 11/26 태웅 의견) |
| 넣을 내용 | 모으는 정보, 쓰는 목적, 보관 기간, 삭제 요청 방법, 외부 AI 모델 API로 보내는 내용, 만 14세 미만 아동 정보의 법정대리인 동의(T78 필수 동의 화면과 같은 내용), 연락처. 사진 속 아이 찾기(얼굴 찾기)는 아직 없는 기능으로 적고, FR-23(얼굴로 우리 아이 찾기)이 들어갈 때 3장 사진 항목과 함께 고친다 |
| 베타 표시 | 비공개 베타에는 가상 데이터만 쓴다는 문장 |

## 3. Data safety (앱 기능 기준 초안)

| 자료 종류 | 모음 | 쓰는 곳 | 비고 |
| --- | --- | --- | --- |
| 이름 | 예 | 교사·학부모·원장 계정, 아동 이름 | 앱 기능 |
| 계정 ID(로그인 아이디) | 예 | 로그인 | 앱 기능·계정 관리 |
| 메시지(앱 안) | 예 | 요청·민원·상담·문의, 알림장 | 앱 기능 |
| 사진 | 예 | 앨범·피드 | 앱 기능 |
| 건강 정보 | 예 | 투약 요청·보호자가 확인한 돌봄 메모 | 공유 아니요, 앱 기능 (README U6, 11/26 태웅 의견) |
| 앱 활동(처리 이력) | 예 | 요청 처리 이력·감사 기록 | 앱 기능 |
| 이메일·위치·연락처·금융 | 아니요 | | 계정에 이메일을 받지 않음(`users` 표에 이메일 없음) |

| 질문 | 초안 답변 |
| --- | --- |
| 전송 중 암호화 | 예 (HTTPS만 사용, NFR-12) |
| 제3자 공유 | 아니요 — OpenAI·LangSmith·AWS는 개발자 대신 처리하는 서비스 제공자라 Play 기준 '공유'가 아님. 대신 '수집'에 넣고 처리방침 4절에 국외 전송을 적음 (11/26 태웅 의견) |
| 삭제 요청 방법 | 확인 필요 — README U5 |

## 4. 콘텐츠 등급 (IARC 설문)

| 항목 | 초안 답변 |
| --- | --- |
| 카테고리 | 참고·교육·생산성 등 업무 앱 계열 (설문 화면에서 고름) |
| 폭력·성·약물·도박 | 없음 |
| 사용자끼리 소통 | 예 — 교사와 학부모가 앱 안에서 메시지를 주고받음 |
| 예상 등급 | 전체 이용가(3세 이상) 수준. 소통 기능 때문에 표시가 붙을 수 있음 |
