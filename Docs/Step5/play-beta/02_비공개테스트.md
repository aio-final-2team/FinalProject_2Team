# 02 비공개 테스트 (Closed testing)

> 2026-11-26 기준 · 계정이 열린 뒤 Console에서 설정

## 트랙

| 항목 | 내용 |
| --- | --- |
| 트랙 | 비공개 테스트(Closed testing) 1개 |
| 테스터 지정 | 이메일 목록 |
| 참여 방법 | Console의 참여 링크(opt-in) → 테스터가 수락 → Play 스토어에서 설치 |
| 첫 릴리스 | T69에서 성주가 AAB 업로드(12/11) |
| 승인 확인 | T76(12/14). 미승인이면 서명 APK로 일정 진행, APK 설치는 Play 배포로 세지 않음(T72) |
| Production | 하지 않음 |

AAB가 올라가기 전에도 트랙 만들기·테스터 목록·피드백 주소는 미리 설정할 수 있어요.

## 테스터

| 구분 | 인원 | 비고 |
| --- | --- | --- |
| 팀원 | 4명 | 지혜를 뺀 팀원 |
| 강사 | 1명 | |
| 외부 지인 | 미정 | 유치원 교사·학부모 역할로 볼 사람 |

- 테스터마다 Play 스토어에 쓰는 **구글 계정 이메일**이 필요해요.
- **이메일은 저장소에 올리지 않아요.** Console 테스터 목록에만 넣고, 이 문서에는 구분·인원만 적어요.
- 테스트 로그인은 모두 가상 계정·가상 데이터로 해요(NFR-12).

## 테스터 안내 순서

1. 테스터에게 구글 계정 이메일 받기
2. Console 테스터 목록에 추가
3. 참여 링크와 가상 로그인 계정 전달
4. 설치 → 로그인 → 요청 보내기 → 상태 확인 (T72·T77 확인 흐름)
5. 피드백 보내기
