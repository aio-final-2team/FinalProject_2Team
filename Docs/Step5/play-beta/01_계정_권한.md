# 01 계정·권한

> 2026-11-26 기준

## 계정

| 항목 | 내용 |
| --- | --- |
| 계정 종류 | 개인(Personal) 개발자 계정. 조직 계정은 D-U-N-S 번호가 필요해서 이번 프로젝트에는 쓰지 않음 |
| 명의·관리자 | 지혜 (개인 구글 계정) |
| 현재 상태 | 구글 계정만 있음. Play Console 개발자 등록 전 |
| 등록비 | $25, 한 번만 냄 — 결제 예정(11/26~이번 주) |
| 신원 확인 | 등록 때 진행 — 예정. 확인에 며칠 걸릴 수 있음 |
| 공개되는 정보 | 개발자 이름·연락처 이메일이 스토어 정보에 보임 → 연락처는 팀용 주소 추천(README U7) |

## 진행 순서

1. Play Console에서 개발자 등록 → 계정 종류 '개인' 선택
2. 등록비 결제
3. 신원 확인 서류 제출 → 결과 대기
4. 확인 끝나면 앱 만들기 (앱 이름·기본 언어 한국어·앱·무료)
5. 팀원 초대 (아래 권한 표)

각 단계 날짜는 아래 기록 표에 적어요.
