## 핵심 반영 내용

- 기획서와 WBS에 필수·선택 범위와 선택 기능의 회귀 대응 조건을 반영했습니다.
- 중간 발표 전 제공 VM을 사용하고, 이후 AWS로 이전하는 계획을 반영했습니다.
- 12/24 브라우저 웹 배포 URL은 별도 제출물이며, Android 앱과 기능·서버를 재사용합니다.
- 생성 모델은 실제 모델 ID로 호출해 정상 응답을 확인하는 절차를 반영했습니다.
- AC-06 권한 시험과 AC-11 베타 피드백의 작업·증거 연결을 반영했습니다.
- STEP 1 원래 마감, 1차 업로드, 보완 날짜를 구분했습니다.
- 원장 현황은 같은 React 앱의 역할별 화면으로 통합했습니다. 브라우저 웹과 Android가 코드와 API 서버를 공유하므로 별도 대시보드 서비스는 배포하지 않습니다.

## 문서 갱신 기준

Word와 Excel 원본을 기준으로 관리합니다. Markdown은 각각 원본 DOCX·XLSX의 UTF-8 열람용 사본이며, 원본을 수정하면 Markdown도 함께 갱신합니다.
