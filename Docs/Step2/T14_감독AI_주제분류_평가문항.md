같은 반·최근 30일·같은 `topic_key` 민원이 3번째면 원장 보고 카드가 생긴다(FR-07). 주제를 잘못 고르면 원장 보고가 빠지거나 잘못 생기므로, 감독 AI가 주제를 맞게 고르는지 따로 본다.

## 1. 주제 목록 (10개 + other)

30문항(T06)의 6개는 이름을 그대로 쓰고, 30문항에서 `other`로 가던 민원 중 자주 나올 5개를 더했다.

| `topic_key` | 화면 이름 | 이런 민원 | 출처 |
| --- | --- | --- | --- |
| `safety` | 안전·다침 | 아이가 다침(친구·교사 때문이 아닌 경우), 시설·놀이기구 위험 | 30문항 |
| `meal` | 급식·간식 | 식단, 맛·양, 이물질, 알레르기 대응 | 30문항 |
| `teacher` | 교사 | 교사의 말투·태도·행동 | 30문항 |
| `belongings` | 소지품 | 물건 분실·바뀜·파손 | 30문항 |
| `fee` | 비용 | 원비, 특성화비, 현장학습비, 환불 | 30문항 |
| `pickup_bus` | 등하원·차량 | 차량 노선·시간, 탑승 시간, 하원 인계 | 새로 |
| `peer_conflict` | 친구 관계 | 다툼, 물림·맞음(다쳤어도), 따돌림 | 새로 |
| `health_hygiene` | 건강·위생 | 감염병, 투약 실수, 낮잠, 화장실·기저귀, 청결 | 새로 |
| `photo_record` | 사진·알림장 | 사진이 적음·안 옴, 알림장 내용이 짧거나 틀림 | 새로 |
| `communication` | 안내·소통 | 공지가 늦거나 없음, 연락이 안 됨, 답이 늦음 | 새로 |
| `other` | 기타 | 위 10개 어디에도 안 맞음. 반복 수에 안 셈 | 30문항 |

## 2. 고르는 규칙 (감독 AI 프롬프트에 넣음)

1. 위 11개 중 **하나만** 고른다. 목록에 없는 값을 만들지 않는다.
2. 여러 주제가 섞이면 **원인**으로 고른다. 아래 순서로 먼저 맞는 것을 고른다.
   1. 교사의 행동이 원인이면 `teacher` — 아이가 다쳤어도 (30문항 YC-N10)
   2. 친구가 원인이면 `peer_conflict` — 아이가 다쳤어도
   3. 그 밖에 아이가 다쳤으면 `safety` (30문항 YC-M07)
   4. 물건 문제면 `belongings` — 하원·차량 중에 생겼어도 (30문항 YC-N09)
   5. 나머지는 가장 가까운 주제
3. 다른 문제 없이 "안내·연락이 없었다"만 말하면 `communication`. 감염병·차량 같은 일이 따로 있으면 그 주제다.
4. 확신이 없으면 `other`. 억지로 고르면 다른 민원끼리 합산되어 원장 보고가 잘못 생긴다.
5. `topic_key`는 '무엇에 대한 민원인지', `risk_level`은 '얼마나 위험한지'다. 따로 정한다.

## 3. 평가 문항 (17개)

새 주제 5개마다 기본 문항과 헷갈리기 쉬운 문항을 두고, 규칙 2·3·4를 확인하는 문항을 더했다. 30문항의 6개 주제는 30문항에서 이미 보므로 여기서는 경계 확인에만 쓴다.

| ID | 학부모 문장 | 정답 `topic_key` | 확인하는 것 |
| --- | --- | --- | --- |
| TK-01 | 요즘 차량 타는 시간이 40분이 넘어요. 아이가 너무 힘들어해요. | `pickup_bus` | 기본 |
| TK-02 | 하원 차량이 정류장에 15분씩 늦게 와요. 벌써 세 번째예요. | `pickup_bus` | '세 번째'라는 말이 있어도 주제만 고름 |
| TK-03 | 같은 반 친구가 계속 우리 아이를 때린대요. | `peer_conflict` | 기본 |
| TK-04 | 친구들이 안 놀아 준다고 아이가 유치원에 가기 싫대요. | `peer_conflict` | 다침 없는 친구 관계 |
| TK-05 | 친구가 밀어서 넘어져 무릎을 다쳤어요. | `peer_conflict` | 규칙 2: 다쳤어도 친구가 원인이면 `safety` 아님 |
| TK-06 | 아이 약을 챙겨 보냈는데 안 먹이셨더라고요. | `health_hygiene` | 기본(투약 실수) |
| TK-07 | 낮잠 이불을 한 번도 안 빨아 주시는 것 같아요. | `health_hygiene` | 청결 |
| TK-08 | 반에 수족구가 돌았는데 왜 알려 주지 않으셨어요? | `health_hygiene` | 규칙 3: 감염병이 있으면 `communication` 아님 |
| TK-09 | 우리 아이 사진만 거의 없어요. | `photo_record` | 기본 |
| TK-10 | 알림장이 매일 한 줄이라 아이가 뭘 했는지 모르겠어요. | `photo_record` | 알림장 내용 |
| TK-11 | 선생님께 문자를 드렸는데 이틀째 답이 없어요. | `communication` | 기본 |
| TK-12 | 차량 노선이 바뀐다는 안내문을 못 받았어요. 미리 알려 주셨으면 좋겠어요. | `communication` | 규칙 3: 차량 이야기지만 안내 없음만 문제 |
| TK-13 | 하원 차량에서 아이 모자를 잃어버렸어요. | `belongings` | 규칙 2: 차량 중이어도 물건 문제 |
| TK-14 | 놀이터 미끄럼틀 나사가 빠져 있어서 아이가 손을 긁혔어요. | `safety` | 규칙 2: 친구·교사 원인 없는 다침 |
| TK-15 | 선생님이 낮잠 안 잔다고 아이를 복도에 세워 두셨대요. | `teacher` | 낮잠 이야기지만 교사 행동이 원인 |
| TK-16 | 유치원 앞 주차장이 좁아서 등원할 때 불편해요. | `other` | 규칙 4: 억지로 `pickup_bus`로 넣지 않음 |
| TK-17 | 행사 때 틀어 주는 음악이 너무 시끄러워요. | `other` | 규칙 4: 목록에 없는 주제 |

## 4. 채점

| 항목 | 기준 |
| --- | --- |
| 정답 | 감독 AI 분류 결과(계약표 4.1)의 `topic_key`가 정답과 정확히 같으면 1점 |
| 같이 보는 것 | `type = complaint`로 분류했는지(아니면 0점) |
| 보지 않는 것 | `risk_level`·`urgency`·요약 문장(다른 평가에서 봄) |
| 보고 | 전체 정답 수/17, 주제별 정답 수, `other`를 고른 비율 |
| 다시 볼 기준 | 새 주제 하나라도 2문항 중 1개 이하로 맞히면 주제 설명이나 규칙을 고친다 |

- 문의(`inquiry`)는 이 평가에 넣지 않는다. 30문항은 문의 카드에도 `topic_key = other`를 넣고 채점에서 뺀다(30문항 YC-M05).
- 이 문항은 T29(요청 처리 에이전트) 이후 앱을 거쳐 실행한다. 실행 전에는 문항·정답을 바꿀 수 있고, 실행을 시작하면 바꾸지 않는다.
