# 유치온 디자인 시스템

- 작성: 2026-11-18 (성주, T12)
- 상태: 기초 규칙과 부품 17종 확정 (2026-11-18, 고르기 화면에서 29개 항목을 보고 고름)
- 범위: 기초 규칙(1~6장)과 부품 17종(7장)이다. 나머지 부품은 화면을 하나씩 다시 짜면서 8장 양식으로 채운다.

## 0. 이 문서가 필요한 이유 (확인한 사실)

| 확인한 것 | 결과 |
|---|---|
| T12 회의 자료의 글자 크기 | **24가지** (9px부터 27px, 12.5·11.5·13.5처럼 소수점 크기 포함) |
| T12 회의 자료의 모서리 둥글기 | **20가지** (2px부터 40px) |
| 11/17 목업 진단 | 학부모 화면과 교사 화면 모두 19/40점. 흐린 글자(2.4:1), 10.5px 글자, 44px보다 작은 버튼이 지적됨 |

값이 화면마다 제각각이라, 기초 단계를 줄여서 고정한다.

### 1.3 색 쓰는 양 (11/18 확정)

- 화면 바탕은 아주 연한 블루(`page`), 카드는 흰색(`card`)이다.
- 브랜드 블루를 넓게 까는 곳은 **학부모 홈 맨 위 제목 칸 하나뿐**이다. 그 칸에는 흰 워드마크를 쓴다.
- 그 밖의 블루는 주 버튼, 링크, 선택 상태, 숫자 배지, 할 일 상태 글자에만 쓴다.
- 종류(문의·상담·민원)에는 색을 쓰지 않는다. 색은 상태와 긴급에만 쓴다.

### 1.4 상태 색 규칙 (11/17 확정, 모양은 11/18)

| 무게 | 표시 | 예 |
|---|---|---|
| 긴급 | 네이비 채움 배지 + 사이렌 아이콘, 줄의 아이콘 칸도 네이비 채움 | 긴급 민원 |
| 할 일·확인 필요 | 블루 굵은 글자 (`accent`) | 확인 필요, 원장 보고, 정보가 더 필요해요 |
| 답 왔음·일반 | 라벤더 굵은 글자 (`lav`) | 답변 도착, 승인됨 |
| 완료 | 민트 굵은 글자 (`ok`) | 완료 |
| 기다림 | 회색 굵은 글자 (`ink2`) | 접수, 보류, 선생님 확인 중 |

색만으로 구분하지 않는다. 상태는 항상 글자로 쓰고, 긴급에는 아이콘을 붙인다.

### 1.6 다크 모드 규칙 (11/18, 대비 계산으로 정함)

| 문제 (계산값) | 정한 것 |
|---|---|
| 네이비 긴급 채움이 다크 카드 위에서 사라짐 (1.01:1) | 다크에서는 긴급을 **밝은 칸 + 네이비 글자**로 뒤집는다 (14.7:1). 가장 밝은 칸이라 긴급이 그대로 가장 눈에 띈다 |
| 넓은 블루를 다크용 밝은 블루(#7d9bff)로 바꾸면 화면이 번쩍임 | 머리 칸과 주 버튼은 두 모드 모두 **브랜드 블루 #2F5BEA + 흰 글자**(5.5:1). 밝은 블루는 글자·링크·작은 표시에만 쓴다 |
| 카드와 바탕 차이가 다크에서 1.09:1, 그림자도 안 보임 | 다크에서는 카드 둘레에 0.5px 선(`edge`)을 두르고, 뜬 면(토스트·시트)은 한 단계 밝은 `raise`를 쓴다 |
| 입력칸 테두리 `sep`이 3:1에 못 미침 (라이트 1.27, 다크 1.41) | 입력칸 테두리는 `line`(라이트 3.05, 다크 4.36)을 쓴다. `sep`은 줄 사이 구분선에만 쓴다 |
| 상태 글자색 | 다크에서 6.3~10.2:1로 모두 통과. 바꾸지 않는다 |

다크 모드는 기기 설정을 따른다. 앱 안에서 바꾸는 버튼은 MVP에 두지 않는다.

## 2. 글자

- 글꼴: Pretendard Variable. 대체 글꼴은 -apple-system, Apple SD Gothic Neo, Noto Sans KR, system-ui 순서다.
- 한국어 줄바꿈은 `word-break: keep-all`, 본문 자간은 -0.01em, 큰 제목 자간은 -0.025em이다.
- 시간·개수처럼 세로로 줄을 맞추는 숫자에는 `tabular-nums`를 쓴다.

### 크기 8단계 (11/18 확정)

| 이름 | 크기/줄높이 | 굵기 | 쓰는 곳 |
|---|---|---|---|
| `display` | 32/38 | 700 | PC 큰 제목 (1024px 이상) |
| `large-title` | **24**/30 | 700 | 휴대폰 화면 제목 (화면 첫 줄) |
| `title` | 20/26 | 700 | 시트 제목, 카드 상세 제목 |
| `headline` | 17/24 | 600 | 목록 줄 제목, 카드 제목 |
| `body` | **16**/24 | 400 | 본문, 입력칸 |
| `callout` | 15/22 | 600 | 버튼 글자 |
| `footnote` | 13/18 | 500 | 시간, 설명 한 줄 |
| `caption` | 12/16 | 600~700 | 상태 글자, 필터 건수, 탭 이름 |

- **최소 글자 크기는 12px**이다. 9·10·10.5·11·11.5px은 모두 12px으로 올린다.
- 본문을 16px로 둔 이유: 휴대폰에서 16px보다 작은 입력칸은 iOS가 화면을 확대한다. 학부모가 읽기도 쉽다.
- 굵기는 400·500·600·700 네 가지만 쓴다.

## 5. 움직임: 살짝 튐 (11/18 확정)

| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| `dur-press` | 100ms, ease-out | 누름 반응 (scale .97, 손가락을 대는 순간) |
| `dur-fast` | 200ms | 색·투명도 바뀜 |
| `dur-move` | 420ms | 시트·토스트가 나타날 때 |
| `ease-move` | cubic-bezier(.34,1.45,.64,1) | 끝에서 조금 넘쳤다 돌아오는 곡선 |
| `ease-out` | cubic-bezier(.2,.9,.25,1) | 사라질 때, 화면 전환 (튀지 않음) |

- 튀는 곡선은 **나타날 때만** 쓴다. 사라질 때와 화면 전환에는 `ease-out`을 쓴다.
- 끌어서 닫는 시트와 토스트는 손가락 속도를 이어받는다.
- 상태 화면의 마크 움직임은 T12 화면지도 2.8을 따른다.
- 움직임 줄이기 설정을 켜면 미끄러짐과 튐을 짧은 페이드로 바꾼다. 투명도 줄이기 설정을 켜면 반투명 바를 불투명하게 바꾼다.

## 6. 쓰기, 접근성, 브랜드

### 6.1 쓰기 규칙

- 학부모 화면의 메뉴와 제목에서는 아이를 "우리 아이"로 부른다. 내용에는 "하린이"처럼 아이 이름을 먼저 쓴다. "우리 애", "내 아이"는 쓰지 않는다.
- 상태 이름은 T04 명세 2장의 역할별 표시 이름 표에서만 가져온다. 학부모용과 교직원용을 따로 쓴다.
- 버튼에는 "보내기", "승인하고 보내기"처럼 하는 일을 적는다. "확인", "예"는 쓰지 않는다.
- 오류 문구에는 무엇이 안 됐는지와 어떻게 하면 되는지를 함께 적는다. 사과 문구는 넣지 않는다.
- "AI 정리", "감독 AI", "임베딩" 같은 내부 용어는 학부모 화면에 쓰지 않는다.

### 6.2 접근성

- 글자 대비는 4.5:1 이상이다. 24px 이상 글자, 아이콘, 입력칸 테두리는 3:1 이상이다.
- 누르는 곳은 **44×44px 이상**이다. 작게 보이는 탭이나 분할 버튼도 누르는 영역은 44px로 둔다.
- 키보드 포커스는 `accent` 2px 테두리에 2px 띄움으로 표시한다.
- 화면마다 제목(h1)을 하나 둔다. 승인·보내기 결과는 화면 읽기 프로그램이 읽어 주도록 알린다(aria-live).

### 6.3 브랜드 마크 (11/17 확정)

| 마크 | 쓰는 곳 | 규칙 |
|---|---|---|
| 말풍선 친구 (8표정) | 학부모 화면의 상태 화면·토스트·안내 | 화면 폭 1/3 이하, 한 화면에 한 번. 32px 이하는 평면판 |
| '온' 심볼 | 교사·원장 화면의 상태 화면·토스트 | 16~24px은 단색판 |
| 로고 모션 B | 앱 시작 1회 (약 3.4초) | 로그인 뒤에는 글자 없이 역할 마크만 |

에셋 원본은 팀 공유 에셋 폴더 `유치온_에셋_최종`(`01_브랜드에셋`, `02_로고모션`)에 있다.

### 6.4 아이콘 (11/18 확정)

- 세트: **Lucide** (ISC 라이선스). 선 굵기 2, 24px 격자, 색은 글자색을 따른다(currentColor).
- 크기: 탭바 24, 목록 줄 아이콘 칸 17, 버튼·배지 안 13~16.
- 종류와 긴급 아이콘:

| 뜻 | Lucide 이름 |
|---|---|
| 문의 | `message-circle-question-mark` (물음표 말풍선) |
| 상담 | `users` (사람들) |
| 민원 | `megaphone` (확성기) |
| 긴급 | `siren` (사이렌) |

- 에셋 `ui-icons` 20종 중 `inquiry`·`consult`·`complaint`·`urgent` 4개만 위 Lucide 아이콘으로 바꾼다.
- **나머지 16종(홈·받은함·알림장·승인·거절·보류 등)은 지금 에셋 `ui-icons`를 그대로 쓴다** (11/18 확정). 두 세트 모두 선 굵기 2, 24px 격자, 둥근 끝이라 함께 쓸 수 있다. 새 아이콘이 더 필요하면 Lucide에서 가져온다.
