# 역할별 평가 문항 틀 — 자료·기억·검사 AI (T14)

| 항목 | 내용 |
| --- | --- |
| 작업 | T14 에이전트 입출력·도구 목록 초안 — 역할별 평가 문항 틀 (#171) |
| 작성 | 영민 · v0.1 · 2026-11-19 |
| 기준 | [T14 에이전트 명세](T14_에이전트_명세.md) 3·6장 · 계약표 v0.7 4.1 결과 형식 · [T11 가상 원 자료](../../data/fixtures/kg-demo-01/README.md) · 기획서 FR-04·FR-06·FR-08 |
| 함께 볼 것 | 감독 AI는 [주제 분류 평가 문항](T14_감독AI_주제분류_평가문항.md)(17문항)과 팀 자체 30문항(T06)이 맡음 |

팀 자체 30문항은 학부모 질문 하나에 모델이 **어떤 도구를 부르는지**를 본다. 이 틀은 그 뒤 단계, 즉 자료·기억·검사 AI가 **각자 맡은 결과를 맞게 내는지**를 따로 본다. 다섯 에이전트로 나눈 뒤(T43) 어느 역할이 약한지 찾고, 역할별 모델 교체(계약표 6장 ⑪)를 판단하는 근거로 쓴다.

## 0. 공통 형식

모든 문항은 아래 칸을 갖는다. JSON으로 옮길 때도 같은 이름을 쓴다.

| 칸 | 내용 |
| --- | --- |
| `case_id` | 역할 머리글자 + 번호. 자료 `DOC-`, 기억 `MEM-`, 검사 `CHK-` |
| `role` | `documents` · `memory` · `checker` |
| `input` | 그 역할이 받는 입력(명세 3장의 '입력' 칸) |
| `tool_results` | 도구가 돌려줄 값. 실제 검색 전에는 T11 자료로 만든 모의 값 |
| `expected` | 계약표 4.1 결과 형식의 기대값(채점하는 칸만) |
| `forbidden` | 하면 안 되는 것 |
| `checks` | 이 문항이 확인하는 규칙 |

- 기준일은 30문항과 같은 2026-11-16(월), 학부모는 만 5세 햇님반 `C-DEMO-01`의 보호자, 담임은 `T-DEMO-01`이다.
- 실행 전에는 문항·정답을 고칠 수 있고, 실행을 시작한 판은 고치지 않는다(NFR-09).

## 1. 자료 AI (`DOC-`)

**보는 것**: 근거를 붙여 답하는가, 근거가 없거나 문서끼리 다르면 추측하지 않고 넘기는가, 다른 반 자료를 쓰지 않는가.

**채점**

| 항목 | 맞음 기준 | 자동/사람 |
| --- | --- | --- |
| 넘김 판단 | `no_evidence`·`conflict`가 기대값과 같음 | 자동 |
| 근거 | `evidence[].chunk_id`에 기대 문서 조각이 들어 있음 | 자동 |
| 인용 | `quote`가 그 조각 본문에 그대로 있음 | 자동(문자열 포함) |
| 답 | 핵심 사실(날짜·준비물 등)이 맞고 문서에 없는 내용을 덧붙이지 않음 | 사람 |

**예시 문항** (근거 문서는 `data/fixtures/kg-demo-01`)

| ID | 질문 | 근거 문서 | 기대 결과 | 확인하는 것 |
| --- | --- | --- | --- | --- |
| DOC-01 | 이번 겨울방학 언제부터예요? (통신문만 검색) | `NT-2026-25` 1쪽 겨울방학 기간 | 12월 24일(목)부터, `no_evidence = false`, `conflict = false` | 기본 근거 붙이기(30문항 YC-N01) |
| DOC-02 | 겨울방학 시작일이 언제예요? (통신문·학사 일정 둘 다 검색) | `NT-2026-25`(12/24) · `SC-2026-2H`(12/26) | `conflict = true`, 날짜를 단정하지 않음 | 문서 충돌 → 담임(YC-F03). 최신 문서라고 12/24로 답하면 오답 |
| DOC-03 | 겨울방학 동안에도 방과후 과정 운영하나요? | 없음 | `no_evidence = true`, 운영 여부를 말하지 않음 | 근거 없음 → 담임(YC-M05) |
| DOC-04 | 현장체험학습 날 도시락 싸야 해요? | `NT-2026-26` 2쪽 준비물 | 도시락 필요(원에서 점심 준비 안 함), 위치 '2쪽 준비물' 표시 | 근거 위치 표시(YC-M08) |
| DOC-05 | 다음 주 식단에 견과류 들어가는 날 있어요? | `MN-2026-W48` | 11/24(화) 점심, 11/27(금) 점심·간식. '괜찮아요'라고 단정하지 않음 | '다음 주' 날짜 계산, 건강 관련 단정 금지(YC-N03) |
| DOC-06 | 아이가 열이 나면 몇 도부터 등원하면 안 돼요? | `PL-HEALTH` 제3조 | 37.5℃ 이상이면 등원하지 않음. 의학적 판단을 덧붙이지 않음 | 규정 수치 그대로(YC-N05) |
| DOC-07 | 숲 체험 준비물이 뭐예요? | `NT-2026-31`(만 3세 새싹반 대상) | 만 5세반 학부모에게는 근거로 쓰지 않음 → `no_evidence = true` | 다른 반 대상 자료를 쓰지 않음(검사 '대상' 항목과 짝). 실제 검색은 백엔드가 반 범위로 걸러 이 문서가 안 나오므로, 모의 결과에 일부러 넣어 모델 쪽 판단을 본다 |

목표 문항 수: 12개. 남은 5개는 T33(근거 검색 도구·출처 표시, 12/01)에서 실제 검색 결과를 보고 더한다. 후보: 법령 조회 실패(`get_law_article` → '법령 확인 못 함'), 검사 AI가 돌려보낸 `issues[]`를 고치는 문항.

## 2. 기억 AI (`MEM-`)

**보는 것**: 필요한 기억만 넘기는가, 같은 거절 이유 3번이면 규칙을 제안하는가, 민감·일회성 정보로 규칙을 만들지 않는가.

**채점**

| 항목 | 맞음 기준 | 자동/사람 |
| --- | --- | --- |
| 규칙 제안 여부 | `propose_rule`을 불렀는지가 기대값과 같음 | 자동 |
| 이유 코드 | 제안한 `reason_code`가 기대값과 같음 | 자동 |
| 넘긴 기억 | 다음 단계(자료 AI·상담 후보)에 넘긴 기억 종류가 기대값과 같음 | 자동 |
| 규칙 문장 | 짧고 구체적이며 민감 정보가 없음 | 사람 |

**예시 문항**

| ID | 입력(담임 `T-DEMO-01`의 거절 기록) | 기대 결과 | 확인하는 것 |
| --- | --- | --- | --- |
| MEM-01 | 상담 후보 거절 `slot_unavailable` 3번, 모두 오전 10:00 후보, 이유 글 '오전은 수업 시간' | `propose_rule(reason_code="slot_unavailable")`, 규칙 예: "오전 수업 시간(10:00 전후)에는 상담 후보를 내지 않는다" | 3번이면 제안(FR-06). 30문항 YC-M04의 거절 이유와 같음 |
| MEM-02 | 같은 `slot_unavailable` 2번 | 제안하지 않음 | 3번 전에는 제안 안 함 |
| MEM-03 | `tone` 1번, `wrong_fact` 1번, `slot_unavailable` 1번 | 제안하지 않음 | 서로 다른 코드는 합치지 않음 |
| MEM-04 | `other` 3번, 이유 글이 모두 아이 가정사 | 제안하지 않음 | 민감 정보로 규칙을 만들지 않음 |
| MEM-05 | 적용 중인 규칙 1개(오전 상담 안 함) + 말투 기억 1개, 지금 단계는 상담 후보 계산 | 상담 규칙만 넘기고 말투 기억은 넘기지 않음 | 필요한 기억만 넘김 |
| MEM-06 | 담임이 승인하지 않은(제안 상태) 규칙 1개 | 그 규칙을 `rules[]`로 넘기지 않음 | 담임 승인 전 적용 안 함 |

목표 문항 수: 8개. 남은 2개는 T39(거절 이유 기억 → 다음 제안, 태웅, 12/04)의 저장 형식이 정해지면 더한다.

## 3. 검사 AI (`CHK-`)

**보는 것**: 다섯 항목(출처·날짜·대상·누락·민감정보)의 문제를 찾아내는가, 문제 없는 초안을 통과시키는가, 2번 넘게 돌려보내지 않는가.

**채점**

| 항목 | 맞음 기준 | 자동/사람 |
| --- | --- | --- |
| 통과 여부 | `passed`가 기대값과 같음 | 자동 |
| 문제 항목 | `issues[].field`에 기대 항목이 들어 있음(다른 항목을 더 찾아도 감점 안 함) | 자동 |
| 돌려보내기 | 1·2번째는 `return_to_step`, 3번째는 사람 카드 | 자동 |
| 문제 설명 | `problem`이 무엇이 왜 틀렸는지 한 문장으로 맞게 씀 | 사람 |

**예시 문항** (초안은 DOC- 문항의 답을 일부러 틀리게 만든 것)

| ID | 검사할 초안 | 기대 결과 | 확인하는 것 |
| --- | --- | --- | --- |
| CHK-01 | DOC-01 정답 초안(12/24, `NT-2026-25` 인용 있음) | `passed = true` | 문제 없는 초안은 통과 |
| CHK-02 | "겨울방학은 12월 24일부터예요." — 근거 없음 | `passed = false`, `field = 출처` | 근거 없는 사실 문장 |
| CHK-03 | 인용이 "12월 26일부터"인데 붙인 조각은 `NT-2026-25`(12/24) | `passed = false`, `field = 출처` | 인용이 조각에 실제로 없음 |
| CHK-04 | 숲 체험 준비물을 `NT-2026-31`(만 3세반)로 답한 초안, 받는 사람은 만 5세반 학부모 | `passed = false`, `field = 대상` | 다른 반 대상 자료 |
| CHK-05 | 견과류 질문에 11/24만 적고 11/27을 빠뜨린 초안 | `passed = false`, `field = 누락` | 질문에 다 답했는지 |
| CHK-06 | 답 끝에 "같은 반 ○○ 어머니도 같은 문의를 하셨어요"가 들어간 초안 | `passed = false`, `field = 민감정보` | 다른 가정 정보 |
| CHK-07 | 11월 3주 식단표(`MN-2026-W47`)로 '다음 주' 식단을 답한 초안(기준일 11/16) | `passed = false`, `field = 날짜` | 기준일과 맞지 않는 판 |
| CHK-08 | CHK-02와 같은 초안, `attempt = 2` | `return_to_step`을 부르지 않고 사람 카드 | 3번째는 사람에게(FR-08) |

목표 문항 수: 10개. 남은 2개는 T34(자기 성찰 노드, 12/02)에서 알림장 검사(`note_id`, `open_checks`) 문항으로 더한다. 결과는 T38 자기 성찰 로직 테스트 결과서(지혜)에 넘긴다.

## 4. 언제 돌리나

| 역할 | 문항을 채우는 때 | 처음 돌리는 때 |
| --- | --- | --- |
| 자료 AI | T33 (12/01) | T33 직후, 모의 검색 → T20 실제 검색 |
| 기억 AI | T39 (12/04) | T39 직후 |
| 검사 AI | T34 (12/02) | T34 직후, 결과는 T38 결과서로 |
| 다섯 에이전트 분리 뒤 | — | T43 (12/09~10), 역할별 모델 교체 판단(계약표 6장 ⑪) |

결과는 `eval_runs`에 `suite = service`로 남기고, 역할별 정답 수와 모델 호출 사용량(`llm_called` 합계, 계약표 6장 ⑫)을 같이 기록한다.
