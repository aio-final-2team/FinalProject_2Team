# 알림장 서비스 데이터 저장 위치표

문서 버전 v0.2 · 2026-11-20 기준 | 작성: 태웅

지혜님이 11/20 디코 #일반에 올린 「알림장 AI에 필요한 데이터」 중 **A. 서비스 안에서 생기는 데이터**를 항목마다 DB 어디에 저장하는지 정리했어요. 멘토링(11/19) 할 일 '기능에 필요한 데이터 목록 정리(11/22)' 중 백엔드 몫이에요. 스키마는 영민님과 같이 확인해요.

- 근거: [DB 스키마 DDL](./db_schema_draft.sql) v0.8, [DB 스키마 설계서](./DB_스키마_설계서.md) v0.8(4.2 테이블별 권한), [API 설계 문서](./API_설계_문서.md) v0.4
- 마이그레이션 0002(아이별 메모), API 30 반 아이 목록, 확인 항목 `kind`·`sentence`·`request_id`는 모두 develop에 들어왔어요(PR #268).
- B. 외부 데이터는 맨 아래에 두 줄로만 적었어요.

## 시연 반

지혜님 글의 '햇살반'은 시연 반을 말해요. 시연 반은 영민님 PR #262에서 **만 4세 별빛반**(`CL-DEMO-01`, 담임 `T-DEMO-01`)으로 정했어요. 시드 아이는 #262 명단 18명과 기존 시험용 하늘·노을 2명을 합쳐 20명이에요.

## 저장 위치표

'누가 보나'는 설계서 4.2 테이블별 권한을 따랐어요. 모두 같은 원 자료만 보고, 화면에서 숨기는 게 아니라 서버가 역할·반을 검사해요.

민감도는 이렇게 나눴어요.

- **높음**: 아이 건강·다침·투약·가정사가 들어갈 수 있어요. 학부모는 자기 아이 것만, 알림장은 발송 뒤에만 봐요. 처리 이력(`events.detail`)에는 비밀값과 불필요한 개인정보를 넣지 않아요(DDL 주석).
- **중간**: 이름, 계정, 요청 번호처럼 아이·보호자를 알아볼 수 있는 정보예요. 아이 이름은 가상 이름만 써요(`children.display_name`).
- **낮음**: 원·반 정보, 반 공통 활동, 평가용 가상 자료예요.

## 따로 저장할 곳이 없는 것

1. **결석**: 출결 칸이 없어요. 지금은 메모에 "결석(보호자 연락: 미열)"처럼 글로 쓰고, 검사 AI가 `kind`='absent'로 짚어요. 빈 메모는 API가 받지 않아서(메모 1~500자), 메모가 없는 아이는 `child_memos`에서 빠지고 아이별 줄도 생기지 않아요. 시연은 이 방식으로 가고, 출결 칸은 필요해지면 따로 정해요.
2. **보호자 18명 연결**: `child_guardians` 표는 있지만 새로 넣은 18명은 보호자가 없어요. 학부모 화면에서 18명 알림장을 다 보여 주려면 가상 보호자 계정과 연결 시드가 필요해요. 서버는 그 아이 보호자가 보낸 요청만 알림장 입력에 모아서, 보호자 요청 20개를 시드로 넣을 때도 이 연결이 먼저 있어야 해요.
3. **'선생님다운' 알림장 예시(말투 3종×10)**: 서비스 표에는 정답 예시를 넣을 곳이 없어요. 영민님이 `data/fixtures/kg-demo-01/daily_notes/`에 파일로 두기로 했어요(#267 리뷰). `memories`(`kind`='tone')에는 담임이 실제로 고친 기록에서 기억 AI가 만든 것만 넣어요. 미리 넣으면 학습한 말투와 우리가 넣은 말투가 섞여요.
4. **수정 이력 10~20쌍**: `ai_original`이 생긴 뒤(다음 주)에 시드로 넣을 수 있어요.
5. **다음 날 일을 미리 보낸 요청**: 서버는 요청을 보낸 날짜(`requests.created_at`의 한국 날짜)로 그날 알림장 입력에 모아요. 11/19에 "내일은 할머니가 데리러 가요"를 보내면 11/19 알림장 입력에 들어가고 11/20에는 안 들어가요. 그 요청이 말하는 날짜를 따로 저장하는 칸은 없어요. 시연에서는 이 경우를 함정(`GR-11`)으로 두고, 칸이 필요한지는 시연 뒤에 정해요.

## B. 외부 데이터

외부 데이터(식단표·가정통신문, 누리과정 용어, 쓰면 안 되는 표현, 실제 알림장 문체)는 지혜님 목록 B를 따라 영민님·지혜님이 모아요. 식단·통신문처럼 AI가 검색해 근거로 쓰는 자료는 `documents`·`document_chunks`에 넣고, 반 대상은 `document_classrooms`로 정해요.
