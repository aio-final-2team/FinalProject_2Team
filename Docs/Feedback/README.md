# Docs/Feedback

피드백을 반영하기 전에 담당자가 쓰는 메모를 사람별 폴더에 둡니다.

## 흐름

1. 강사님·멘토님·팀원 피드백은 디스코드 `#피드백` 채널에 올립니다. 첫 줄에 누가 준 피드백인지(강사님·멘토님·이름)만 적으면 되고, 사진도 됩니다.
2. 봇 계정 `태웅's 클로드`가 그 글에 스레드를 열고 번호(`FB-001`)를 매긴 뒤, 할 일을 항목(`FB-001-1`, `FB-001-2` …)으로 나눠 담당자를 멘션합니다.
3. 담당자는 항목 앞 표시를 보고 처리합니다.
   - `[문서]` 기획서·WBS 문구를 바꿔야 하는 일: 자기 폴더에 항목 번호로 `.md` 메모를 만들어, 평소처럼 자기 브랜치에서 `develop`으로 PR을 올립니다. 예: `Docs/Feedback/taewoong/FB-001-1.md`
   - `[작업]` 기획서·WBS는 그대로 두고 작업만 하면 되는 일: 메모 없이 작업하고, 그 작업 PR 본문에 번호(`FB-001-1`)만 적습니다.
4. 지혜님이 `[문서]` 메모를 모아 기획서·WBS·GitHub Projects에 반영합니다.
5. 작업하다 생긴 문제도 다시 `#피드백`에 올리면 1번부터 같은 흐름으로 돕니다.

## 메모 양식 (`[문서]` 항목)

```
피드백: FB-001-1
고칠 곳: 기획서 3장 FR-04 수용 기준 / WBS T06 요구사항 칸
바꾸기 전: (지금 적혀 있는 문장)
바꾼 후: (이렇게 바꿔 달라는 문장)
```

메모는 반영 전 제안입니다. 기획서·WBS 원본 파일은 고치지 않고, 바꿀 문장만 그대로 적어 주면 지혜님이 옮겨 붙입니다. 여러 줄이면 줄글이든 목록이든 편하게 씁니다.

각자 자기 폴더 파일만 만들기 때문에 다른 사람 PR과 겹치지 않습니다.
