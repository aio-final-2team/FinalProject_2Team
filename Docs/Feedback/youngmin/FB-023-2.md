# FB-023-2 알림장 민감 표시 조정

- 입력 묶음: 2026-11-26 `daily_note_trap_cases.json` 및 같은 데모 요청 자료. gpt-6-luna로 전 3회, 검사 프롬프트 조정 후 3회 실행. 상세 결과와 실제 모델 usage는 `data/evaluation/daily_note/runs/2026-11-26_{8_before,9_after}_run*.json`에 있어요.
- 원인: 친구 갈등 메모 ND-09의 기존 run2에서는 검사기가 메모에 `other_child`만 남기고 `sensitive`는 보호자 요청에만 남겼어요. 서로 다른 출처에 붙은 확인을 같은 의미로 처리한 프롬프트 경계가 원인이었어요. 이번 전 3회에서는 ND-09가 모두 통과했지만, 재발 방지를 위해 두 확인이 서로 대신하지 못한다고 명시했어요.
- 조정 파일: `agents/prompts/checker.md`. 갈등 메모 항목별 `sensitive`와 별도 `other_child` 동시 기록, 날짜·결석 확인 우선순위를 명확히 했어요. 일상적인 참여 선택과 실제로 다치지 않은 아찔한 상황은 별도 위험 단서가 없으면 `sensitive`로 표시하지 않도록 좁혔어요.
