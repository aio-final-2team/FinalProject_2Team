# FB-022-5 위험 분류 실제 모델 시험

- 기준: `origin/develop` `49edbe5`; 결과와 문항은 `FB-022-5_결과.json`, `FB-022-5_cases.json`에 있어요.
- 방법: 팀 서버 설정으로 맞춘 뒤 `pgvector/pg16` 임시 로컬 컨테이너를 만들고 데모·문서 시드를 적재했어요. 공용 DB나 팀 서버는 쓰지 않았어요. `parent01`로 실제 `/api/v1/requests`를 호출해 생성부터 감독 분류, LangGraph, 카드 생성까지 확인했어요.
- 설정: `LLM_MODEL_SUPERVISOR=gpt-6-luna`, `ANSWER_WRITER=graph`, `REQUEST_AGENT=app.modules.requests.graph_agent:run_request`, `REQUEST_COLLAB_GRAPH=1`, `DATA_BACKEND=db`.
- 결과: 긴급 안전 5/5에서 원장 보고 카드가 생성되고 담임 카드도 유지됐어요. 일반 건강 5/5는 원장 보고로 올라가지 않았고 담임 카드가 생성됐어요. 전체 기대 결과 10/10 통과.
- 모델 증거: 감독 모델이 문항마다 실제 호출됐어요(10회). 위험·종류 제안과 검증 뒤 최종 분류는 결과 JSON에 함께 기록했어요. 머리 부딪힘/구토와 땅콩 알레르기 반응에서 모델이 허용 목록 밖 위험 종류 문구를 냈지만, 최종은 `uncertain`으로 검증돼 원장 보고로 이어졌어요. 일반 건강 문의의 `health` 등 비허용 위험 종류는 최종 위험을 올리지 않았어요.
- 실제 전체 호출: 32회(감독 10, 문서 17, 검사 5), 입력 60,007 토큰·출력 18,503 토큰·합계 78,510 토큰. 실제 API usage와 호출 시간을 수집했어요.
