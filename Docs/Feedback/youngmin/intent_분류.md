# 문의 알림/부탁(intent) 분류 계약

## 출력

- 감독 분류 결과 dict에 `intent` 키를 포함한다.
- 허용값은 `notice`와 `ask`다.
- `notice`는 문의(`inquiry`)에서 보호자가 사실·상태를 알리는 경우다.
- `ask`는 관찰·처리·답변을 요구하거나, 알림과 부탁이 섞이거나, 판단이 애매한 경우다.
- 상담(`consultation`), 민원(`complaint`), 투약(`medication`), 귀가(`pickup`)는 `ask`로 고정한다.
- 값 누락, 허용되지 않은 값, 모델 오류는 `ask`로 기본 처리한다.

## 태웅님에게 넘길 연결 계약

서버는 분류 결과의 `intent`를 읽는다. 키 이름은 `intent`, 값은 `notice | ask`, 기본값은 `ask`다. 이번 변경은 감독 분류 dict에 값만 추가하며 DB 저장, 요청 API, 알림장 입력/제외 동작은 변경하지 않았다. `notice` 요청의 알림장 제외와 저장은 서버 연결 작업에서 처리한다.
