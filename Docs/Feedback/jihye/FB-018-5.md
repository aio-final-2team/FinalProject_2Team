피드백: FB-018-5 [작업] 평가 기록을 상태 전이 설계·자기 성찰 결과서에 연결하기

한 일: [알림장 에이전트 흐름 §7.2](../../Step2/알림장_에이전트_흐름.md)에 [기존 알림장 평가 및 원시 실행 기록](../../../data/evaluation/daily_note/runs/README.md)을 연결하고, T25·T34에서 확인할 상태 전이와 T38에 남길 증거를 정리했다([PR #295](https://github.com/aio-final-2team/FinalProject_2Team/pull/295)).

기획서·WBS 반영:

- 고칠 곳: WBS T38 완료 기준
- 바꾸기 전: 검사 노드 돌려보내기 사례(입력·실패 이유·재시도·최종 결과)가 표로 남음
- 바꾼 후: T25 상태 전이와 T34 검사 노드에 평가 케이스·원시 실행 링크를 연결한다. 결과서에는 입력, 검사 지적, 재시도 횟수와 전후 상태, 사람 확인 전환, 최종 결과를 기록한다. 기존 알림장 평가는 케이스를 고르는 근거로 사용한다(data/evaluation/daily_note/runs/README.md).

- 고칠 곳: WBS T38 요구사항
- 바꾸기 전: FR-08
- 바꾼 후: FR-08, NFR-09

남은 일: T25 상태 전이 설계와 T38 자기 성찰 결과서에 케이스별 회차·전후 상태·종료 조건·사람 인계의 실제 실행 증거를 연결한다. 기존 알림장 평가 기록은 시험 사례 선정과 비교에 사용한다.
