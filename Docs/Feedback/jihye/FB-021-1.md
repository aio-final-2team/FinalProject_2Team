이상했던 점:
1. 식사 줄에 원 자료의 굵게 표시 `**`가 글자로 보인다(`**땅콩조림⑬**`). 담임 알림장 상세·담임 홈·학부모 홈 세 곳 모두.
2. 지아·지안은 AI가 아이 메모 줄을 빼고 확인 항목만 남겼다. 그래서 지아 알림장은 투약 메모 없이 나갔다. 이 확인 카드에는 줄을 넣는 버튼이 없어, 넣으려면 담임이 직접 써야 한다.
3. 준비물 '11/27(금) 김장 체험'이 실행일과 같은 날이라 '가정에서 준비할 것'이 당일 행사가 됐다(11/20 입력값을 그대로 씀).
4. 보호자 요청이 빠져서 지아는 투약 요청이 아니라 메모 때문에 걸렸다.
5. 리허설서 3장 순서표의 버튼 이름이 실제 화면과 다르다('다 읽었어요 · 확인' → '확인하기', '모두 이대로 사용' → '모두 문제 없음으로 옮기기').
6. 초안을 API로 만들어서 화면의 '관찰 기록'은 0명, 아이 상세 '오늘 기록'은 "기록이 없어서 반 활동만 들어갔어요"로 보였다.
