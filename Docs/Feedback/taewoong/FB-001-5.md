## 1

고칠 곳: 기획서 11장 결정 기록 표 '배포 서버' 행, 마지막 칸(강사·매니저 확인 내용)

바꾸기 전:
AWS 구성·비용·비밀값·백업·복구와 웹 배포 URL의 확인 근거를 기록

바꾼 후:
비용 근거(11/18 기준, 서울 리전 공개 단가). EC2 t3.large $0.104/시간 × 11/17~1/4 상시 가동 1,152시간 ≈ $120, EBS gp3 40GB ≈ $6, 고정 IP $0.005/시간 ≈ $6, 합계 약 $133(팀 크레딧 $300 중). t3.xlarge로 올리면 하루 약 $2.5가 늘어난다. 추가 사용량: Rekognition 사진 1장 $0.0012(가상 사진 수백 장 기준 $1 미만), 데이터 전송은 월 100GB까지 무료. 스냅샷·NAT 게이트웨이·로드밸런서는 만들지 않는다. 팀 계정은 비용 화면(Cost Explorer·Budgets) 권한이 없어서, 태웅이 매주 월요일 리소스 목록(EC2·EBS·IP·S3·Rekognition)으로 다시 계산해 디코에 올리고, 실제 청구액은 강사님 비용 확인 계정으로 확인을 요청한다. 위 금액은 개발 기간 서버 추정이며, 실제 유치원 운영비는 T66 배포 아키텍처 설계도에서 따로 계산한다.
