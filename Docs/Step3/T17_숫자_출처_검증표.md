> 결론: 7줄 중 6줄의 출처와 산식을 확인했다. **"알림장 사진 전송 강요 73.2%"는 원문 항목을 잘못 옮긴 것이라 기획서를 40.5%로 고쳤다**(4장). 1년 차 원아 약 2,990명은 시군구 파일로는 재현되지 않아 '부분 재현'으로 둔다. [확인 예정] 1줄은 T23 인터뷰로 넘긴다.

## 1. 검증 방법

| 판정 | 뜻 |
| --- | --- |
| 일치 | 원문 또는 계산 파일로 같은 값이 다시 나옴 |
| 수정 | 원문과 달라 기획서를 고침. 고치기 전 값과 근거를 4장에 남김 |
| 부분 재현 | 산식은 확인했지만 입력값 일부가 남아 있지 않아 같은 값이 나오지 않음 |
| 확인 필요 | 팀 자료로는 확인할 수 없어 원자료를 다시 받아야 함 |

확인 순서는 다음과 같다.

1. 레포 기록(커밋·보관 문서)에서 숫자가 처음 들어온 곳을 찾았다. 11/16 첫 커밋부터 있었고, 출처는 11/13 회의 캡처로 적혀 있었다.
2. 디스코드 11/10~18 기록(메시지 611건·첨부 90건)에서 숫자가 처음 나온 메시지와 공유 자료를 찾았다.
3. 산식을 만든 태웅님께 원자료와 계산 파일을 받아 다시 계산했다(11/23).

## 3. 추정 산식

### 3.1 시장 규모 (5번 줄)

가격 가정은 **원아 1명당 월 1,000원**이다. 11/23 팀 결정에 따라 어린이집을 포함한 범위를 그대로 쓰고, 범위를 기획서에 함께 적는다.

| 기획서 값 | 대상 | 원아 수 | 원자료 | 재계산 |
| --- | --- | ---: | --- | ---: |
| 연 158억 | 유치원 + 어린이집 전체 | 1,313,040명 | 유치원 469,304명 (교육통계 2026.4.1) + 어린이집 843,736명 (사회보장정보원 보육통계 2026.10) | 157.6억 원 |
| 연 83억 (원장 구매) | 사립유치원 + 민간·법인 어린이집 | 695,026명 | 사립유치원 330,214명 (유치원알리미 2026년 2차 공시, 사립 2,773곳 합) + 민간 307,631 + 법인단체 17,138 + 사회복지법인 40,043 (같은 보육통계) | 83.4억 원 |
| 1년 차 0.4억 | 1·2차 지역 유료 기대 18곳 | 약 2,990명 | 유치원마다 원아 수 × 유료 전환 확률의 합 (태웅) | 0.36억 원 |

- 158억은 157.6억을 반올림한 값이다. 131만으로 줄여 곱하면 157.2억이 나오지만 원자료 합은 1,313,040명이다.
- **1년 차 약 2,990명은 부분 재현이다.** 유치원별 값이 없어 시군구 파일로 계산하면(시군구 원아 × 유료 기대 ÷ 사립유치원 수) 1차 약 740명 + 2차 약 1,920명 = **약 2,660명(0.32억)**이 나온다. 어느 쪽이든 0.3~0.4억 범위다.
- 참고: 유치원만 기준으로 하면 유치원 전체 56.3억(469,304명), 사립유치원 39.6억(330,214명)이다. 기획서 본문에는 쓰지 않는다.

### 3.2 원장 수락 (6번 줄 앞부분)

기관별 수락 확률 모델(타겟 지도): 기준 15%(10~25%), 상한 45%, 기준 집단은 비수도권·원아 60~99명이다. 수도권 ×1.5, 원아 규모 ×1.7/1.3/0.7, 홈페이지 ×1.2, 정원 충원율 ×1.1/0.85, 부담금 ×1.15/0.9, 2년 미만 교사 50% 이상 ×1.1을 곱한다. 시범 → 유료 전환은 20%로 가정한다.

| 지역 | 시군구 | 사립유치원 | 시범 기대 | 유료 기대 | 원아 |
| --- | --- | ---: | ---: | ---: | ---: |
| 1차 (서울 동남권) | 송파 | 26 | 9.97 | 1.99 | 3,775 |
| | 강동 | 21 | 7.52 | 1.50 | 3,149 |
| | 강남 | 16 | 5.12 | 1.02 | 2,086 |
| | 서초 | 12 | 4.06 | 0.81 | 1,356 |
| | **합계** | **75** | **26.67** | **5.32** | 10,366 |
| 2차 (경기 남부) | 화성 | 58 | 21.73 | 4.35 | 9,112 |
| | 수원 | 74 | 26.16 | 5.23 | 9,571 |
| | 용인 | 48 | 17.34 | 3.47 | 7,804 |
| | **합계** | **180** | **65.23** | **13.05** | 26,487 |

- 1차 기획서 값 "75곳 → 시범 27곳 → 유료 5곳"은 75 → 26.67 → 5.32를 반올림한 값이다. 타겟 지도의 범위는 시범 19~32곳, 유료 2~7곳이다.
- 1·2차 유료 기대 합은 18.37곳이다 (3.1의 18곳).

### 3.3 학부모 이용률 (6번 줄 뒷부분)

**이용률 = 기준 45% × 최종 배수**다. 최종 배수는 나이·소득·맞벌이·신도시 배수의 곱이고, 낮게·높게 범위와 상한 85%가 있다. 시군구 파일 230곳 모두 이 식과 맞는다.

| 시군구 | 이용률 기본 | 최종 배수 |
| --- | ---: | ---: |
| 서울 서초구 | 62.9% | 1.397 |
| 서울 송파구 | 59.5% | 1.322 |
| 경기 화성시 | 55.9% | 1.242 |
| 전남광주통합특별시 목포시 | 40.2% | 0.893 |
| 울산 동구 | 39.6% | 0.881 |
| 경남 거제시 | 39.5% | 0.878 |

- "40~63%"는 **지방 산업도시와 서초의 비교**다. 전국 최저는 경북 봉화군 37.3%라서 전국 범위로 읽으면 안 된다. 기획서 출처 칸에 이 뜻을 적었다.

## 4. 기획서 수정 이력과 근거

| 위치 | 고치기 전 | 고친 뒤 | 근거 |
| --- | --- | --- | --- |
| 1.3 4번 줄 숫자 | 알림장 사진 전송 강요 **73.2%** | 모바일 사진 전송 압박 **40.5%** | 전교조 원문에서 73.2%는 '놀이이야기 문서 작성 압박' 항목이고, 사진 전송 압박은 40.5%다. 11/12 #저장용 첨부 기획서(1112_.docx)에는 맞게 적혀 있었고, 이후 옮기는 과정에서 항목이 바뀌었다. 11/23 팀 결정: 원문과 다른 인용은 기획서를 고치고 근거를 남긴다 |
| 1.3 4·5·6번 줄 출처 칸 | 교사 설문 / 원아 1명당 월 1,000원 가정 + 공공데이터 원아 수 / 공공데이터에 배수를 얹은 계산 | 조사 이름·시점, 대상 원아 범위, 산식 요약을 적고 이 검증표를 연결 | 완료 기준(원문 링크·대상·기준 연도·추정 산식) |

고치지 않은 것:

- **158억·83억**: 어린이집을 포함한 범위를 그대로 쓴다(11/23 팀 결정). 범위는 출처 칸에 적었다.
- **45,559명**: 시군구 파일 합(45,552명)과 7명 차이가 나지만, 어느 쪽이 공시 원값인지 확인하지 못해 두었다(5장).
