# agents/prompts

버전 관리할 에이전트 프롬프트를 둡니다. 내용의 기준은 [T14 에이전트 명세](../../Docs/Step2/T14_에이전트_명세.md)입니다.

| 파일 | 에이전트 | 들어 있는 것 |
| --- | --- | --- |
| `common.md` | 모두 | 지금 상황(날짜·질문한 사람·이 요청의 아이, 범위는 도구가 지킴), 사람 승인·지어내기 금지·개인정보, 도구 실패 공통 규칙 |
| `supervisor.md` | 감독 AI | 요청 분류의 원칙: 주제(`topic_key`) 11개, 위험 등급과 판단 필요 이유(`risk_reason`), 권한 밖 여부, 알림/부탁(`intent`). 낱말 규칙은 모델이 없을 때의 대역(`request_rules.py`)에만 있습니다 |
| `documents.md` | 자료 AI | 근거 인용 원칙, 근거 없음·자료끼리 다를 때 쓰는 법, 법령 인용, 알림장 초안 쓰기(메모·요청·처리 결과 한 줄에 있는 사실만) |
| `memory.md` | 기억 AI | 보호자 글에서 기억 후보 고르기, 말투 비교, 같은 거절 이유가 세 번 쌓이면 규칙 문장·`rule_json` 제안. 민감 정보는 저장 안 함 |
| `checker.md` | 검사 AI | 출처·날짜·대상·누락·민감정보 대조, 알림장 확인 항목(`problem` 한 줄·`action` 한 줄·버튼 `kind`), 돌려보내기는 코드가 최대 2번 |
| `gather.md` | 자료 찾는 AI | 질문에 답할 근거를 범위가 정해진 도구(문서·관찰 기록·보낸 알림장·투약·귀가·예보·법령)로 스스로 찾는 원칙. 답은 쓰지 않습니다 |

## 쓰는 법

- 에이전트마다 `common.md` 뒤에 자기 파일을 붙여 시스템 프롬프트로 씁니다.
- `{today}`처럼 중괄호로 감싼 칸은 실행할 때 지금 요청 정보로 채웁니다. 질문한 사람·이 요청의 아이 이름은 `_common()`이 '지금 상황'에 줄로 더하고, 기관·반·아이·보호자 ID는 모델에 주지 않고 도구가 범위를 지킵니다(계약표 4장).
- STEP 3(T29)은 에이전트 하나로 돌리므로 `common.md` + `supervisor.md`를 씁니다. 팀 자체 30문항도 이 조합으로 채점합니다. 다섯 에이전트로 나누는 T43부터 역할별 파일을 따로 씁니다.
- `route_request`·`notify_staff`·`find_saved_answer`는 학부모 대화에서 모델이 부르는 도구가 아니라 그래프 단계에서 부릅니다. 그래서 `supervisor.md`에는 넣지 않았습니다.
- 파일 맨 위 주석의 `version`을 바꾸면 평가 결과에 같이 남깁니다(NFR-09). 평가를 시작한 판은 고치지 않고 새 판을 만듭니다.
